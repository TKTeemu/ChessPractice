HOW TO INSTALL CHESSBOARD ON WINDOWS 11
=======================================

Chessboard is a free chess program for analysing games, playing against
the computer, and practising openings, middlegames and endgames.

You do not need any programming knowledge. Everything is done by
clicking. It takes about 10 minutes.

You need:
  - a Windows 11 computer
  - an internet connection
  - at least 500 MB of free disk space

There are three steps. Please do them in this order.


STEP 1: DOWNLOAD AND UNPACK CHESSBOARD
--------------------------------------
Skip the download if you already have the zip file.

  1. Open this page in your web browser:
     https://github.com/TKTeemu/ChessPractice

  2. Click the green "Code" button, then "Download ZIP".

  3. Open your Downloads folder and find "ChessPractice-main.zip".

  4. Right-click the zip file and choose "Extract All...".
     Then click "Extract".
     IMPORTANT: The program will not work from inside the zip file.
     It must be extracted.

  5. Open the new folder. If there is another "ChessPractice-main"
     folder inside it, open that one too. You are in the right place
     when you can see the files "Install.bat" and "Chessboard.bat".

     You can move this folder somewhere else, such as Documents, if you
     want to. Do this now, before the next steps.


STEP 2: RUN THE SETUP
---------------------
This step downloads the parts Chessboard needs, about 100 MB in total:
Python, which the program is written in, and Stockfish, the chess engine
that plays against you. Everything goes inside the Chessboard folder.
Nothing is installed on Windows itself, and you do not need to know
anything about Python. If your computer already has Python, it is not
changed or used.

  1. In the Chessboard folder from Step 1, double-click "Install.bat".
     (Windows may hide the ".bat" and show just "Install".)

  2. Windows may show a blue box saying "Windows protected your PC".
     This is normal for files downloaded from the internet. Click
     "More info", then "Run anyway". If you see a box asking "Do you
     want to run this file?" instead, click "Run".

  3. A black window opens and shows the progress in four parts.
     The Stockfish download can take a few minutes. Just wait.

  4. When you see "Everything is ready", press any key on the keyboard.
     The window closes.

If you see any other message instead of "Everything is ready", read what
it says and follow it. See also "If something goes wrong" below.


STEP 3: START CHESSBOARD
------------------------
  1. Double-click "Chessboard.bat". The chessboard opens.
     Use this file every time you want to play. If Windows shows the
     blue box again, click "More info", then "Run anyway".

  2. Check that Stockfish works: open the "Game" menu and choose
     "Play vs Computer...". You should be able to choose Stockfish as the
     opponent. If only "Random moves" is offered, see "Installing
     Stockfish by hand" below.

Tip: to get an icon on your desktop, right-click "Chessboard.bat", then
choose "Show more options", then "Send to", then "Desktop (create
shortcut)".

The installation is now complete.


INSTALLING STOCKFISH BY HAND
----------------------------
You only need this if Install.bat could not install Stockfish, for
example because of a firewall.

The file must end up in exactly this place, with exactly this name:

    (your Chessboard folder)\engines\stockfish\stockfish.exe

  1. Make file extensions visible, so that you can see the full name of
     the file: in File Explorer, click "View", then "Show", then
     "File name extensions".

  2. Download Stockfish by opening this link in your browser:
     https://github.com/official-stockfish/Stockfish/releases/download/sf_19/stockfish-windows-x86-64-universal.zip

  3. In your Downloads folder, right-click the downloaded zip file,
     choose "Extract All...", then click "Extract".

  4. Open the new folder, and then the "stockfish" folder inside it.

  5. Find the file "stockfish-windows-x86-64-universal.exe". Right-click
     it and choose the Copy icon.

  6. Open your Chessboard folder, then "engines", then "stockfish".
     Right-click an empty area and choose the Paste icon.

  7. Right-click the copied file, choose the Rename icon, and change the
     name to exactly:

         stockfish.exe

     Check that the name is not "stockfish.exe.exe".

  8. Double-click "Install.bat" again. The last part should now say:

         Done: engines\stockfish\stockfish.exe

     Install.bat also tests that Stockfish runs. If the name or the folder
     inside "engines\stockfish" is slightly wrong, it corrects them.

When you are finished, the "engines\stockfish" folder should contain:

    Copying.txt
    README.txt
    stockfish.exe


IF SOMETHING GOES WRONG
-----------------------
"The program files were not found next to this file"
    You are still inside the zip file. Go back to Step 1 and use
    "Extract All...".

"Chessboard cannot save files in this folder"
    The Chessboard folder is in a place where Windows does not let
    programs write, such as "C:\Program Files". Move the whole folder to
    your Documents folder and run Install.bat again there.

"Windows protected your PC"
    Click "More info", then "Run anyway".

The setup says it failed, or a download does not work
    Check your internet connection and run Install.bat again. It is safe
    to run as many times as you like.

Your antivirus program blocks or removes stockfish.exe
    Stockfish is a well-known free chess engine. Allow "stockfish.exe" in
    your antivirus settings, then run Install.bat again.

Your antivirus program blocks python.exe or pythonw.exe
    These are Python's own files from python.org, in the "python" folder
    inside the Chessboard folder. Allow them in your antivirus settings,
    then run Install.bat again.

"Adding Tcl/Tk, part 2 of the setup, did not work"
    Another program may be installing or updating at the same time. Wait
    a few minutes, or restart the computer, and run Install.bat again.

A box says "Chessboard cannot start"
    Run Install.bat again and read the last message it shows.

Double-clicking Chessboard.bat does nothing
    Look in the Chessboard folder for a file called "error.log". If you
    ask someone for help, send them that file.


REMOVING CHESSBOARD
-------------------
  1. Save anything you want to keep from the "Games" folder inside the
     Chessboard folder, if there is one.

  2. Delete the Chessboard folder. That is all: Chessboard keeps
     everything, including its own Python, inside that folder.

Older versions of Chessboard asked you to install Python 3.15 yourself.
That Python is no longer needed. If you installed it only for
Chessboard, you can uninstall "Python 3.15.2" in Settings, then "Apps",
then "Installed apps". Keep it if other programs use it.
